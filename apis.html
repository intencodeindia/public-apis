API Documentation

Base URL: /api

🔹 Family Members API

GET /family-members/{user_id}

Fetch all family members for a specific user (employee).

POST /family-members/{user_id}

Create a new family member.

{
  "name": "John Doe",
  "email": "john@example.com",
  "phone": "9876543210",
  "relationship": "Brother",
  "gender": "Male",
  "nationality": "Indian",
  "nationality_proof": "[File Upload - Optional]",
  "profile_photo": "[File Upload - Optional]"
}
GET /family-members/{user_id}/{id}

Get a specific family member's details.

PUT /family-members/{user_id}/{id}

Update a family member.

{
  "name": "John D.",
  "email": "john.d@example.com",
  "phone": "9876543211",
  "relationship": "Cousin",
  "gender": "Male",
  "nationality": "Indian",
  "nationality_proof": "[File Upload - Optional]",
  "profile_photo": "[File Upload - Optional]"
}
DELETE /family-members/{user_id}/{id}

Delete a family member.

🔹 Documents API

GET /documents/{user_id}

List all documents uploaded by a specific employee.

POST /documents/{user_id}

Upload a new document.

{
  "document": "[File Upload - Required]",
  "documentId": "doc123",
  "name": "Passport",
  "document_type": "ID Proof",
  "issue_date": "2023-05-01",
  "issue_place": "Delhi",
  "visa_provider": "XYZ Travels",
  "expiry_date": "2025-12-31",
  "additional_info": "Scanned copy of passport",
  "family_member_id": 2
}
GET /documents/{user_id}/{id}

View details of a specific document.

PUT /documents/{user_id}/{id}

Update a document.

{
  "document": "[File Upload - Optional]",
  "documentId": "doc123",
  "name": "Updated Passport",
  "document_type": "ID Proof",
  "issue_date": "2024-06-01",
  "issue_place": "Mumbai",
  "visa_provider": "ABC Tours",
  "expiry_date": "2026-12-31",
  "additional_info": "Renewed copy",
  "family_member_id": 2
}
DELETE /documents/{user_id}/{id}

Delete a document.

Note: All endpoints require apiKeyAuth middleware. For file uploads, use multipart/form-data.
