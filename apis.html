API Documentation

Base URL: /api

🔹 Family Members API

GET /family-members/{user_id}

Fetch all family members for a specific user.

POST /family-members/{user_id}

Create a new family member.

{
  "name": "John Doe",
  "email": "john@example.com",
  "phone": "9876543210",
  "gender": "Male",
  "relationship": "Brother",
  "nationality": "Indian",
  "nationality_proof": "[File Upload - Optional]",
  "profile_photo": "[File Upload - Optional]"
}
PUT /family-members/{user_id}/{id}

Update a family member.

{
  "name": "John D.",
  "email": "john.d@example.com",
  "phone": "9876543211",
  "gender": "Male",
  "relationship": "Cousin",
  "nationality": "Indian",
  "nationality_proof": "[File Upload - Optional]",
  "profile_photo": "[File Upload - Optional]"
}
DELETE /family-members/{user_id}/{id}

Delete a family member.

🔹 Documents API

GET /documents/{user_id}

List all documents uploaded by a specific user.

POST /documents/{user_id}

Upload a new document.

{
  "document": "[File Upload - Required]",
  "documentId": "doc123",
  "name": "Passport",
  "document_type": "Visa",
  "issue_date": "2024-01-01",
  "expiry_date": "2025-12-31",
  "issue_place": "Mumbai",
  "visa_provider": "VFS Global",
  "additional_info": "Primary visa",
  "file_type": "PDF",
  "family_member_id": 2
}

🔹 Leave Request API

POST /leave/apply

Apply for a leave request including optional family participants.

{
  "employee_id": 1,
  "leave_type": "vacation",
  "is_half_day": false,
  "leave_from_date": "2025-08-10",
  "leave_to_date": "2025-08-15",
  "travel_type": "business",
  "travel_from": "Mumbai",
  "travel_to": "Bangalore",
  "ticket_provider": "MakeMyTrip",
  "remarks": "Annual team retreat",
  "family_participants": [
    {
      "family_member_id": 2,
      "travel_from": "Mumbai",
      "travel_to": "Goa",
      "leave_from_date": "2025-08-11",
      "leave_to_date": "2025-08-16"
    }
  ]
}
POST /leave/approve/{id}

Approve a specific leave request.

POST /leave/reject/{id}

Reject a specific leave request.

Note: All endpoints require apiKeyAuth middleware. For file uploads, use multipart/form-data.
